# JeuDevinettes - Exercice 2

## Description
Jeu de devinettes en Java où l'utilisateur doit trouver 
un nombre secret entre 1 et 100.

## Règles du jeu
- Le programme génère un nombre aléatoire entre 1 et 100
- Le joueur a 10 essais maximum
- Après chaque essai, le programme indique si c'est trop grand ou trop petit
- Si le joueur trouve → il gagne !
- Si les 10 essais sont épuisés → il perd !

## Comment exécuter
1. Ouvrir le projet dans IntelliJ IDEA
2. Exécuter la classe Main.java
3. Entrer des nombres dans la console pour jouer
